# Security Policy

## Supported Versions

Only the latest release. Each merge to `main` releases a new image, and tjzimmerman.com runs it.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/zimmertr/Personal-Website/security/advisories/new).
Do not open a public issue for security problems.

Include what you found, where it lives (file, workflow, image, or the live site), and how to reproduce it.

What to expect:

- **Acknowledgement** within a few days. This is a one-person project, so response times are best effort.
- **Fix**: a confirmed vulnerability is fixed in the next release.
- **Credit** in the advisory, unless you'd rather not.

## Scope

In scope: the site, its image, its nginx config and the CI workflows.

Out of scope: nginx itself. Report issues in it to its maintainers.

There is no bounty program. Reports are still appreciated.
